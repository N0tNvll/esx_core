Run `npm install` and `npm test` here (Node.js 20+). The runner can also use an existing Fengari installation under `tools/node_modules`.

The suite exercises the existing numeric point API, additive object points and arrays, grid invalidation, resource cleanup, callback failure/removal, and sphere/box/polygon containment. FiveM vectors, scheduler, and GLM are simulated. Check real GLM geometry, debug drawing, and resource restarts in FiveM before deployment.

Source: https://github.com/esx-framework/esx_core/pull/1755 at ce0c40e36e806866ebb0ec7a7928eee496a303dd. Integrated selectively to retain the existing point and table APIs.
